# Virtuālā izstāde — Latvijas arhitektūra

## Projekta apraksts
Mācību projekta tēma ir Latvijas arhitektūra. Vietnē apkopoti deviņi piemēri no dažādiem laikmetiem: pilis, vēsturiskas ēkas, pilsētvide un mūsdienu arhitektūra.

## Komandas dalībnieki
- Somats Bečers — HTML struktūra un objektu apraksti (piedāvātais darba sadalījums).
- Arturs Valujevs — CSS noformējums, responsīvais dizains un JavaScript karuselis (piedāvātais darba sadalījums).

## GitHub repozitorijs
GitHub repozitorijs vēl nav izveidots. Pēc tā izveides ievieto šeit īsto saiti.

## Izmantotās tehnoloģijas
- HTML5 — semantiskajai lapas struktūrai.
- CSS3 — Box Model, Flexbox, Grid un responsīvajam dizainam.
- JavaScript — interaktīvam attēlu karuselim.
- GitHub — projekta versiju kontrolei un komandas sadarbībai.

## Vietnes funkcijas
- Galvene, navigācija, izstādes apraksts un kājene.
- Deviņu Latvijas arhitektūras fotogrāfiju galerija ar nosaukumiem un aprakstiem.
- Karuselis ar iepriekšējo/nākamo pogu un automātisku attēlu maiņu.
- Poga automātiskās maiņas apturēšanai un atsākšanai.
- Izkārtojums datoram un mobilajam ekrānam.
- Fotogrāfiju autori un licences norādītas vietnes sadaļā “Fotogrāfiju autori un licences”.

## Vietnes palaišana
Atver `index.html` tīmekļa pārlūkā. Papildu serveris nav vajadzīgs.
Lai ielādētu fotogrāfijas no Wikimedia Commons, nepieciešams interneta savienojums. Četras pirmās fotogrāfijas ir saglabātas projekta `assets` mapē.

## GitHub darba soļi
1. Izveido kopīgu GitHub repozitoriju un pievieno komandas biedru.
2. Ievieto repozitorijā visus projekta failus, ieskaitot `README.md` un `assets` mapi.
3. Katrs dalībnieks veic savas izmaiņas un saglabā tās ar commit un push.
4. Ievieto repozitorija saiti šajā README un iesniedz ZIP arhīvu Moodle.

Pirms iesniegšanas pārbaudiet, vai darba sadalījums atbilst tam, ko katrs dalībnieks tiešām paveica.
