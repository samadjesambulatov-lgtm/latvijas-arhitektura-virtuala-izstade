# Virtuālā izstāde — Latvijas arhitektūra

## Projekta apraksts
Mācību projekta tēma ir Latvijas arhitektūra. Vietnē apkopoti deviņi piemēri no dažādiem laikmetiem: pilis, vēsturiskas ēkas, pilsētvide un mūsdienu arhitektūra.

## Komandas dalībnieki
- Somats Bečers — HTML struktūra un objektu apraksti (piedāvātais darba sadalījums).
- Arturs Valujevs — CSS noformējums, responsīvais dizains un JavaScript karuselis (piedāvātais darba sadalījums).

## GitHub repozitorijs
Projekta pirmkods un izstrādes vēsture: https://github.com/samadjesambulatov-lgtm/latvijas-arhitektura-virtuala-izstade

## Izmantotās tehnoloģijas
- HTML5 — semantiskajai lapas struktūrai.
- CSS3 — Box Model, Flexbox, Grid un responsīvajam dizainam.
- JavaScript — interaktīvam attēlu karuselim.
- GitHub — projekta versiju kontrolei un komandas sadarbībai.

## Vietnes funkcijas
- Galvene, navigācija, izstādes apraksts un kājene.
- Deviņu Latvijas arhitektūras objektu galerija ar nosaukumiem un aprakstiem.
- Karuselis ar iepriekšējo/nākamo pogu un automātisku attēlu maiņu.
- Poga automātiskās maiņas apturēšanai un atsākšanai.
- Izkārtojums datoram un mobilajam ekrānam.
- Fotogrāfiju autori un avoti norādīti vietnes sadaļā “Fotogrāfiju autori un licences”.

## Vietnes palaišana
Atver `index.html` tīmekļa pārlūkā. Papildu serveris nav vajadzīgs. Wikimedia Commons fotogrāfiju ielādei nepieciešams internets. Četras fotogrāfijas atrodas projekta `assets` mapē.
