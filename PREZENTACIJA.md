# Prezentācijas plāns

## Ko teikt

Labdien! Mūsu praktiskā darba tēma ir Latvijas arhitektūra. Mēs izveidojām virtuālu izstādi, kurā parādītas ēkas un arhitektūras objekti no dažādiem Latvijas novadiem un laikmetiem.

Vietnes sākumā ir izstādes nosaukums un īss apraksts. Navigācijas izvēlne ļauj pāriet uz informāciju par izstādi, galeriju un attēlu karuseli.

Galerijā ir deviņas īstas fotogrāfijas: Rīgas panorāma, jūgendstila nams, Rundāles pils, Turaidas pils, Melngalvju nams, Rīgas Doms, Cēsu pils, Kuldīgas vecpilsēta un Gaismas pils. Katram attēlam ir nosaukums un īss apraksts. Fotogrāfiju avoti norādīti vietnes apakšā.

Vietnes struktūru veidojām ar HTML5 un semantiskajiem elementiem, piemēram, `header`, `nav`, `main`, `section`, `article` un `footer`. CSS failā izmantojām Box Model, Flexbox un CSS Grid. Ar Media Queries pielāgojām vietni mazākiem ekrāniem.

JavaScript nodrošina attēlu karuseli. Attēlus var pārslēgt ar iepriekšējā un nākamā attēla pogām. Karuselis pārslēdzas arī automātiski, un to var apturēt vai atsākt.

Projektu var atvērt, pārlūkā palaižot `index.html`. Fotogrāfijām vajadzīgs interneta savienojums. Avotu saites atrodas vietnes apakšā. Projekta README failā ir informācija par tehnoloģijām un GitHub darba soļiem.

## Ko parādīt

1. Parādīt sākuma sadaļu un navigācijas izvēlni.
2. Pāriet uz galeriju un īsi parādīt deviņas kartītes.
3. Atvērt karuseli, nospiest “Nākamais” un “Iepriekšējais”.
4. Apturēt automātisko pārslēgšanu un pēc tam to atsākt.
5. Samazināt pārlūka logu, lai parādītu responsīvo izkārtojumu.
6. Parādīt avotu saites, README un GitHub repozitoriju pēc tā izveides.
